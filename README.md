# 喜馬拉雅瑜伽全書

把 YouTube 上散落的優質瑜伽教學，變成一門**結構完整、連結全數驗證、實證來源可查**的免費課程網站。

**線上課程**：<https://himalaya-yoga.pages.dev>

從 Yama、Niyama 與經典，經呼吸覺察、體式與 Nadi Shodhana，到 Pratyahara、
Dharana 與 Dhyana，**三階 15 章 89 個單元**。每個單元都告訴你三件事：
**怎麼判斷自己做對了**、**今天該練什麼**、以及**這套說法在科學文獻裡有多少支持**；
傳承立場與坊間做法分歧的地方，另外標在「**傳承怎麼說**」。

> **傳承歸屬。** 本站的章節次第參考喜馬拉雅瑜伽傳承（Swami Rama of the Himalayas，AHYMSIN）
> 公開的教學架構編排，但**本站是獨立策展的自學整理，不隸屬於該傳承，也不是其官方或授權教材**，
> 站內影片亦非傳承的教學內容。傳承的正式資訊請見 <https://www.himalayanyogatradition.com>。
> 傳承的核心是 **transmission**——師徒之間經驗與能量的傳遞，這是一個網站在結構上就做不到的事。
> 這門課能給的是安全性、次第的地圖與文獻的座標，不是傳承本身。

## 這門課跟其他瑜伽課的差別

### 一、章節順序照傳承的次第排，不是照體式難度排

次第取自 Swami Veda Bharati 的〈[The Himalayan Yoga Tradition](https://www.himalayanyogatradition.com/HimalayanTradition.pdf)〉——
該文逐節列出這套系統的組成順序；三階分組（覺察／控制／綜合）取自 HYT-TTP 的 Level One/Two/Three。

```
淨化思想與情緒 ──→ 呼吸覺察 ──→ 體式與自我觀察 ──→ Nadi Shodhana
(CH2)              (CH4)        (CH5–CH7)          (CH9)
                                                      │
        Dhyana ←── Dharana ←── Pratyahara ←───────────┘
        (CH13)     (CH12)      (CH11)
```

這個順序跟坊間課程有四處明顯不同，每一處都寫進了對應單元的「傳承怎麼說」：

| | 傳承的位置 | 坊間常見的位置 |
|---|---|---|
| **Yama / Niyama** | 系統的**第一個**組成（思想與情緒的淨化） | 哲學章，排在最後 |
| **體式** | mindfulness 的載體——「a major component in the practice of postures is self-awareness」 | 課程主體本身 |
| **Bhastrika** | Nadi Shodhana 的**預備**練習 | 進階／高強度技法 |
| **脈輪** | 屬 Dharana，且明文警告未先掌握 sumeru pranayama 與灌頂就教喚醒「可能導致傷害」 | 獨立成章，早早就教 |

呼吸的地基（CH4）仍排在體式之前，這一點兩邊的理據剛好一致：傳承說呼吸覺察
「始於正念，而後專門化成冥想練習的第一步」，而生理上體式停留的品質也取決於能不能維持鼻呼吸。
真正被移到體式之後的，是**專門化**的 Nadi Shodhana（CH9）。

Kumbhaka 是唯一一處本課程與傳承明確分歧的技法：傳承直言**不鼓勵**刻意止息，
只教正確呼吸並等待 kevala-kumbhaka 自然發生。本課程仍把技法與風險交代完整，但把這個立場標在單元裡。

### 二、每個單元都能自測

體式與呼吸法單元都附「**怎麼判斷自己做對了**」——不是「注意保持核心穩定」這種
無法判定的句子，而是你今天躺下來、靠牆站、計時三分鐘就能得到答案的判準。

> 進入頭倒立前先過三關：①海豚式停留 60 秒肩膀不塌、②靠牆抬單腿 30 秒骨盆不歪、
> ③頸椎無疼痛、麻感或旋轉受限病史。三項有任一項不過就繼續練前導，不要靠牆硬上。

過不了就別往下——這是進度判準，不是鼓勵語。

### 三、傳統怎麼說，跟文獻怎麼說，分開寫

這是這門課最不討喜、但最重要的部分。每個實證查核都把
`traditional_claim`（傳統與坊間怎麼說）與 `what_evidence_shows`（文獻實際測到什麼）
分成兩欄，**不一致時就明白寫出不一致**。

首頁的立場頁列出七個最根本的結論，包括對課程自己不利的，這裡摘五個：

| | 結論 | 分級 |
|---|---|---|
| 1 | 脈輪沒有解剖學對應物，是注意力引導框架而非生理系統 | `傳統框架・無實證對應` |
| 2 | 瑜伽對慢性下背痛與焦慮有效，但**不優於其他等量運動** | `證據中等` |
| 3 | 慢速呼吸對自律神經的效果，是全課證據最紮實的一項 | `證據中等` |
| 4 | 「排毒」「提升免疫力」缺乏可測量的證據支持 | `證據互斥` |
| 5 | 倒立與極端後彎的嚴重風險罕見但真實，不是零 | `證據有限` |

證據分級多了一級 `traditional`——用在脈輪、prana 這類**不屬於可驗證命題**的框架上。
這比硬說「證據不足」誠實：那不是還沒被證明，而是本來就不是同一種主張。

課程照傳統把技術教完整，但把療效宣稱分開查證。CH12 有完整的七大脈輪內容，
同一個網站也寫著脈輪沒有解剖學基礎——這不矛盾：
**傳統框架作為注意力引導工具有實用價值，作為生理學主張則沒有證據。**

### 四、傳承立場一律附逐字出處

「傳承怎麼說」不是轉述，也不是我對傳承的詮釋。17 條註記底下各自掛著
**傳承自己公開文件的英文原文**、頁碼，以及可以直接點開核對的 PDF 深連結，
適用處另附《瑜伽經》經號：

> The living Himalayan tradition of meditation does not encourage practices like kumbhaka.
>
> — Swami Veda Bharati〈The Himalayan Yoga Tradition〉p.3

共 **30 筆逐字出處**，來源是傳承的三份公開文件：
[〈The Himalayan Yoga Tradition〉PDF](https://www.himalayanyogatradition.com/HimalayanTradition.pdf)、
[TTP 課程進程頁](https://www.himalayanyogatradition.com/progression.html)、
[課程內容頁](https://www.himalayanyogatradition.com/features.html)。

中文說明與英文原文分開放：說明是我寫的，引文一個字都沒改。
兩者不一致的話，以引文為準——所以連結才要能點得開。

這條規則寫進了 `make audit`：**只要有單元寫了 `tradition` 卻沒有 `traditionRefs`，
或任何一筆出處缺引文、出處或連結，稽核直接報錯**，不是警告。
沒有來源的傳承宣稱進不了這個 repo。

### 五、連結真的活著

幾百個影片欄位最大的風險是連結是捏造的。所以有三層關卡：

| 關卡 | 做什麼 | 打網路嗎 |
|---|---|---|
| 策展階段 | video ID **只能**取自 `tools/ytsearch.py` 的即時搜尋結果 | 是 |
| `make audit` | 設定檔、配額、影片長度、實證欄位全查一遍 | 否，確定性 |
| `make verify` | 每個 YouTube 連結重打 oEmbed、每個 PMID 重打 PubMed API、每個傳承出處連結重打一次 | 是 |

**不信任任何上游宣稱**，包括策展 agent 自稱驗證過的。PMID 一律取自 PubMed
E-utilities 回傳值，`make verify` 會逐筆比對標題對不對得上。

| | CH2 | 淨化思想與情緒：Yama、Niyama 與經典 | 3 |
| | CH3 | 安全、身體地圖與練習設定 | 5 |
| | CH4 | 呼吸覺察：橫膈呼吸的地基 | 4 |

| | CH10 | 能量鎖、手印與淨化法 | 5 |

| | CH12 | Dharana：Trataka、專注與脈輪 | 9 |

每個單元有一堂主課加 5–7 支延伸影片，分成
**正位拆解**、**跟練**、**替代與輔具**、**進階變化**四類。
其中 17 個單元另附「**傳承怎麼說**」，逐條引自傳承的公開文件。

**單元 id 刻意沒有跟著章號重編**（例如 Yama/Niyama 仍是 `ch11-u2`，現在排在 CH2）。
id 是實證對照（`oe-units.json` 的 `unit` 欄）、giscus 討論串與進度追蹤的鍵，
重編會讓既有討論與進度全部對不上；顯示章號由 `course.config.json` 決定，兩者本來就不必一致。

## 網站有什麼

- **首頁** — 用法三步驟、立場摘要、章節總覽
- **課程內容** — 章節樹、自我判準、依身體部位分面篩選、證據註記
- **上課模式** — 左側嵌入播放（走 `youtube-nocookie.com`）、右側播放清單，
  欄寬可拖曳、`?tab=player&play=12` 深連結
- **立場** — 七則實證結論與原始文獻

外加全文搜尋、localStorage 進度追蹤、深淺色主題、鍵盤快捷鍵（按 `?`）、
每支影片一串 giscus 討論。

**首屏零外部請求**：設計語彙用 CSS 變數自行實作，Lucide 圖示打包成內嵌 sprite。
只有按下播放時才連 YouTube、點開討論時才連 giscus。

## 驗證結果

| 關卡 | 結果 |
|---|---|
| `make audit` | **零錯誤**，3 個警告（逐條說明如下） |
| `make verify`（連結） | **601 / 601 有效（100%）** |
| `make verify`（引用） | **199 / 199 通過（100%）**，148 個不重複 PMID |
| `make test` | 18 / 18 通過 |
| 版面 | 章節、單元、出處**全部展開**下，桌機與 390px 手機皆 0 水平溢出；1578 個圖示引用全數解析 |
| 重排後 | 15 章全數渲染、89 單元一個不漏、17 個「傳承怎麼說」區塊都出得來 |
| 傳承出處 | 17 條立場 · **30 筆逐字出處全數附連結**（`make audit` 缺一就報錯） |

### 三個警告，以及為什麼接受

**一、10 支影片超出長度區間。** 全部集中在 CH1 與 CH2 的哲學單元，是 1–2 小時的學術講座
（Edwin Bryant 講《瑜伽經》1:46、Swami Sarvapriyananda 講《薄伽梵歌》系列）。
把上限放寬到兩小時會讓這個檢查對其他章節失效，所以選擇留下警告。

重排之後這個代價變大了：傳承把思想與情緒的淨化排在系統的第一位，所以這兩章從最後移到了最前面，
**新學員一開頭就會撞上全課最「重」的內容**。務實的建議是先看短講座建立框架，
長講座邊練邊回頭補——但章節順序仍照傳承排，不因為完成率而讓步。

**二、4 支影片觀看數低於 3,000。** 分別是輕喉鎖（1,879）、拜日式的文獻源流（2,232）、
師徒制濫權的系統性分析（1,859）與高控制團體機制（2,801）。這四個主題的高流量替代品
不是內容農場就是獵奇敘事，選擇低流量但來源可靠的版本，每一支都在 `why` 寫明理由。

**三、35 個體式／呼吸法單元中只有 4 個有單元層級實證。** 這是框架設計而非疏漏——
個別體式沒有專屬文獻（「下犬式」沒有自己的 RCT），所以體式單元的實證掛在
**類別層級**（站姿與負重體式、後彎體式、開髖體式…共 29 類、117 篇引用），
顯示在單元的「這類練習的實證」區塊。單元層級查核保留給真正有專屬文獻的主題，
例如頭倒立的眼壓、Kapalbhati 的腦血流、孕期瑜伽的安全性。

## 修過的框架 bug

這門課是 curate-course 框架的第二個主題，換主題與依傳承次第重排的過程，
順便暴露出五個**不會報錯、或只會靜靜給出錯誤結果**的問題，都已修掉：

| 位置 | 問題 |
|---|---|
| `src/build/build.py` | 首頁立場聲明寫死成 `concept-1..3`，第 4 則之後被靜靜丟掉 |
| `src/web/js/render.js` | 文案佔位符只認得 `{units}` / `{videos}`，且 `{videos}` 錯對到 `video_slots`，與建置期的 `token_map()` 不一致 |
| `course.config.json` | `stance.intro` 走 `esc()` 逸出，寫 `<strong>` 會被當純文字印在頁面上（只有 `stance.outro` 是 raw） |
| `course/taxonomy/practices.py` | 用「關節」當比對關鍵字，會吸走所有 `target` 含髖／膝／肩關節的項目（命中 82 → 修正後 30） |
| `src/build/audit.py` | `sprite_icons()` 拿 `json.loads` 去解析 `icons.js` 裡的 **JS 陣列**——任何 formatter 補上 trailing comma，整個稽核就當場 crash。改成用 regex 抽名稱 |

## 本機開發

需要 [uv](https://docs.astral.sh/uv/)。建置腳本只用 Python 標準庫。

```bash
make build     # course/ → dist/，含配額驗證與 SEO 產出
make audit     # 離線稽核（不打網路，可放 CI）
make verify    # 重驗每個影片連結、PMID 與傳承出處連結（打真實 API）
make serve     # http://localhost:8899
make check     # lint + test + build + audit，提交前跑這個
make deploy    # 部署到 Cloudflare Pages
```

策展與實證用的工具：

```bash
python3 tools/ytsearch.py "nadi shodhana tutorial" 15   # 搜尋 + 中繼資料，一次完成
python3 tools/pubmed.py search "yoga insomnia meta-analysis" 10
python3 tools/merge_meta.py                              # 合併各章 meta 並交叉稽核
```

工作流程與踩過的坑寫在：

## 免責聲明

本課程為運動與身心練習指引，**不構成醫療診斷或治療建議**。

若你有高血壓、心血管疾病、青光眼或視網膜疾患、癲癇、椎間盤突出、骨質疏鬆、
近期手術史，或正在懷孕，開始前請先諮詢醫師，並詳讀 CH3 的禁忌對照表。

「實證強度」註記附有 PubMed 原始文獻連結，反映查詢當下的文獻狀態，不等於臨床指引。
